## 6. 學到的事

- **完整解耦的價值**：adapter（-06）做完之後，router（-07）只是 wire-up，~25 分鐘完成
  + 11 tests pass。如果直接寫 router（沒抽 adapter），estimated 會至少 1-2 小時
  且難測試
- **TestClient 不用啟動真 server** — 直接 wrap FastAPI app instance，比起跑
  uvicorn + curl 快 50 倍
- **POST 統一 over POST/GET 混合** — 對 demo / 前端同事比較好懂；GET 留給「無 body」
  純查詢（例如 GET /api/cost/datasets 列出可用 dataset）
- **OpenAPI swagger UI 是 free 的** — FastAPI 自動產，pydantic schema 就是文件，
  劉老師約 demo 時 `/docs` 就是 API 規格書
