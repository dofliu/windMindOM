## 6. 學到的事

- **Journal 主題不需要 SVG / sharp / react-icons** — 純粹 pptxgenjs 文字 + 線條 + 色塊就能做出書冊風，比 Forest/Navy/Frieren/Naruto 簡單；極簡留白 + 印刷符號（§ — · →）+ 字距加寬就是 Journal 的視覺核心
- **PowerPoint COM 在 Windows 不允許隱藏視窗**（`Visible=msoFalse` 報錯），但用 `Visible=msoTrue` 也不會跳 GUI 的可見視窗，背景開檔轉 PDF 仍 silent，可作為 LibreOffice 的替代方案
- **物件最小化（策略 B）**：把 fill / line 直接寫在 addText 上而不是疊一個獨立 shape，可顯著減少 pptx 物件數，未來用戶在 PowerPoint 手動編輯時點一下就選到完整區塊
- **Outline 先對齊**這個策略在這個 issue 救了不少時間 — 用戶選 Journal 而不是原本的 Navy，但因為內容已拍板，只需要改色票/字型/裝飾，故事不用重寫
